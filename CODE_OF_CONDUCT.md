# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Expected behavior

- Be respectful, welcoming, and constructive in issues, pull requests, and reviews.
- Focus feedback on the code and ideas, not the person.
- Respect differing viewpoints and experience levels, and accept constructive criticism gracefully.
- Harassment, personal attacks, trolling, or discriminatory behavior will not be tolerated.

## Reporting

If you experience or witness unacceptable behavior, please contact the maintainer **@bejulian1** privately via GitHub.
